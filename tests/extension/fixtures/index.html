  • no-title.htmlVelmi málo textu (UI-06)
  • editable.htmlEditovatelná pole se nesmí číst ani posílat (UI-06)

  • html-title.htmlJeden blok bez shody, název s HTML (UI-07)
  • long-block.htmlVelmi dlouhý blok (UI-09)
