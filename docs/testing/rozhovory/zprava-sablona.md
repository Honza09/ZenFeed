## 6. Omezení

Doplnit konkrétně po sběru odpovědí:

| Omezení | Popis |
|---|---|
| Vzorek | Počet a velikost, nereprezentativnost. |
| Forma | Písemný dotazník místo rozhovorů (odchylka od proposalu §5): bez doptávání, stručnější odpovědi. |
| Výběr | Odkud respondenti pocházejí; kdo se neozval; sebevýběr (odpovídají ti, kteří chtějí). |
| Zkreslení autora otázek | Co mohlo ovlivnit otázky a výklad; jak bylo omezeno. |
| Jiné | |

## 7. Kontrola před zveřejněním

- ☐ Žádné jméno, e-mail, telefon, zaměstnavatel, přesný věk, bydliště ani adresa stránky identifikující osobu.
- ☐ Všechna zjištění jsou označena jako hypotézy.
- ☐ Každé tvrzení má odkaz na zápis a otázku.
- ☐ Rozpory a odmítnutí jsou uvedeny stejně prominentně jako podpora.
